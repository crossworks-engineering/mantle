# Add knowledge and ask for it

Put something into your brain, then ask for it back in your own words.

## Add something

Pick any of these:

- **A note**: open **Notes**, click **New**, write a few lines and save.
- **A file**: open **Files** and drop a PDF, Word document or spreadsheet anywhere on the screen.
- **A sentence to the assistant**: "Make a note that the gate code is 4821."

Mantle reads what you add by itself. It writes a summary, indexes it for search, pulls out the facts, and records the people, places and projects it mentions. There is no "remember this" to say. A small item is ready in moments; a large file takes a minute or two.

## Ask for it back

Open the assistant and ask, even vaguely:

> What was that note about the gate?

It searches by meaning, so you do not need the exact title or words. It answers and can show the source it used.

## If it does not find it

- **Search by meaning is off**: the **Memory** step of the setup wizard was skipped. Set up an embedding model in **Settings > Embedding**.
- **The file is still being read**: wait a minute and ask again.
