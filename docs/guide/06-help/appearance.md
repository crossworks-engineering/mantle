## Appearance

Appearance sets how Jackdaw looks. Most choices apply as you click.

- **Mode**: Light, Dark or System.
- **Color theme**: pick one of about forty full palettes. Type in the filter box to find one by name.
- **Fonts**: set the **Interface font**, the **Wordmark** (the brain's name in the header), **Pages and Notes** (the editor, shared pages and PDF export) and the **Peer name**, each with its own size.
- **Avatar style**: the look of every generated avatar. **Logo**: upload your own logo.
- **Backgrounds**: a generated backdrop for the Menu, Brand, Chat and Activity areas. Each can be Off. Only the menu has one at first.

Pick a theme by contrast as well as colour. The status colours (success, warning, error) need to stand apart so a failed job is easy to spot.

## Assistant

The assistant cannot change appearance. Set it here.

## Technical

- Colours are theme tokens. Each surface asks for a role such as background, card or border, and the theme supplies the colour. Backgrounds take their colours from the theme too.
- Mode is stored in this browser. Theme, fonts, logo and backgrounds are stored on the brain, so they apply to everyone who signs in.
- Fonts are variable fonts, downloaded only when something uses them.
- If a screen looks unstyled after an update, reload the page.
