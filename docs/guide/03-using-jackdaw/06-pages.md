# Pages

Write rich documents in Jackdaw, have the assistant edit them, and choose who can read them.

A page holds headings, callouts, columns, tables, to-do lists, code, images and diagrams. Use a page for writing you would hand to someone: a proposal, a runbook, meeting notes.

## Write a page

1. Open **Pages** and create a page.
2. Type. Press `/` for the block menu. Type `@` to link a person, an entity or another page.
3. Your edits save as a **draft** as you type.
4. Click **Commit** to make the draft the live page and index it into the brain.

Readers and the assistant's search see the last commit, never a half-written draft.

You can also paste a markdown document straight in. Headings, callouts, tables and task lists become real blocks.

## Edit as markdown

Click **Markdown** in the page header to edit the raw markdown. Click it again to return to the formatted view. Nothing is lost either way.

## Let the assistant edit

1. Open the page.
2. Open the assistant and ask: "Restructure this into sections", "Add a section on the generator service", "Draw a flow diagram of the approval steps".
3. The changes land in the draft. Click **Review** to see what changed against the live page. Discard or restore single blocks from there.
4. Click **Commit** when you are happy.

From any screen you can also ask: "Write this up as a page called Site Handover."

## Choose who can read it

Click **Access** in the page header and pick a level:

| Level | Who can read it |
|---|---|
| **Admin** | Only admins. |
| **Team** | Team members, signed in with their own logins. |
| **Client** | Signed-in clients, and the team. |
| **Public** | Anyone with the link. |

Only **Public** makes a link. See [Team and members](12-team.md).

## Download

The **Download** menu exports the page as Markdown, Word or PDF.
