# Notes and journal

Capture quick knowledge in **Notes**, and tell the assistant who you are in the **Journal**.

## Notes

A note is plain markdown with a title and tags. It is the fastest way to get something into the brain. Each note is summarised and indexed when you save it.

1. Open **Notes** and click **New**.
2. Type, then save.

Or ask the assistant:

- "Make a note: the borehole pump was cycling every 4 minutes today."
- "Add to the supplier note: two-week lead time."
- "What did I write down about the borehole?"

Ask it to *add* to a note and it appends, so a note can work as a running log. The assistant cannot delete notes.

When a note grows into something you would hand to someone, make it a [page](06-pages.md).

## Journal

The Journal holds short entries about you. Every agent reads them in every conversation, so you never explain yourself twice.

It has three views:

| View | What it holds |
|---|---|
| **You** | What you wrote about yourself. |
| **Agent notes** | What agents learned while working for you, grouped by agent. |
| **Questions** | Questions the agents want you to answer. |

### Write an entry

1. Open **Journal** and click **New**.
2. Write one or two sentences in the first person. For example: "I run a small engineering firm. Most of my work is site inspections."
3. Pick a kind: **Identity**, **Context**, **Preference** or **Goal**.
4. Click **Save journal entry**.

Or say it in chat: "Journal that I started a new job today." The assistant writes it in your voice.

### Answer the agents' questions

When an agent gets stuck for lack of a fact, it files a question. Open **Questions**, type the answer under it, and click **Answer question**. Your answer becomes a new entry, and the question leaves every agent's list. An agent may also ask you one in chat when it is relevant.

### Review what agents learned

**Agent notes** holds lessons and expectations agents recorded about working for you. Edit a note to correct it, or delete one that is wrong. The **Learned** section on **Settings > Agents** links to each agent's notes.
