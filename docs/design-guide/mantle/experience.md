# Experience mode

Adapted for Mantle from Impeccable v4.9.1 `SKILL.md` (Modes) and `reference/new-work.md` (Apache 2.0). Changed: condensed; the shared Persuade and Experience rules follow below this file.

On an **Experience** surface the visitor is inside the work itself: a portfolio, a gallery, a showcase, an interactive explainer, a piece meant to be explored. In Mantle it is usually a Present canvas.

- **The work leads from the first view.** No hero banner in front of it, no intro paragraph before it. The interface recedes until it is needed.
- **Ask what leads, how exploring unfolds, and which transition matters.** Design that path first: the first thing seen, the second, how the visitor moves between pieces.
- **Full commitment.** Bold, distinct, with a point of view. The world may own and structure the page.
- **One decision per screen.** Which piece to open, not filters, sorting and tags all at once.
- **Build the technique itself.** If the world names one (a canvas drawing, 3D, a view transition, generative motion), build it with the frame's libraries (`canvas_library`), not a static imitation.
- **Motion is material**: one authored, orchestrated moment, bounded in cost, content visible by default, reduced motion honoured.
- Heuristics such as help text and power-user shortcuts may not apply here; keyboard access and contrast always do.

The Persuade and Experience rules from Impeccable follow.
