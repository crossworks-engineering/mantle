# D3 in a mini app

Version: d3 7.9.0, as this brain's app runtime serves it.
Source: the D3 documentation (d3js.org) and its 6.0 and 7.0 release notes.
Written for Mantle, not copied.

## Import

```tsx
import * as d3 from 'd3';
```

A namespace import (no default export). The bare name only: `d3-scale` and
the other `d3-*` packages are refused, they are all inside `d3`. The frame's
import map serves it; it is not bundled into the app.

## In a React component

Two ways, and the first is usually the better one:

- **D3 for the maths, React for the marks.** Scales (`d3.scaleLinear`,
  `d3.scaleBand`, `d3.scaleTime`), shapes (`d3.line`, `d3.area`, `d3.arc`,
  `d3.pie`), `scale.ticks()` and `d3.max` in render or `useMemo`; React draws
  the `<svg>`, `<rect>` and `<path>` elements. No effect, no cleanup, and
  React owns the DOM.
- **D3 owns a node.** For a force graph, a zoom or `d3.axisBottom`: give
  D3 an `<svg ref>` and run `d3.select(ref.current)` in a `useEffect`.
  React must render nothing inside that node. Cleanup stops what runs:
  `simulation.stop()`, `selection.on('.zoom', null)`.
- Colours: `style={{ fill: 'var(--chart-1)' }}` or a Tailwind class
  (`fill-primary`). An SVG presentation attribute (`fill="var(--x)"`) does
  not read CSS variables.
- Size: read the container with a `ResizeObserver` into state, or draw in a
  fixed `viewBox` and let the SVG scale (`className="w-full h-auto"`).
- **`d3.csvParse` and `d3.tsvParse` do not work here**: they build their row
  function with `new Function`, which the app frame's policy refuses. Use
  `d3.csvParseRows` (arrays, no eval), JSON, or rows from `host.db`.
- No network: `d3.json(url)` and `d3.csv(url)` fail. Data comes from
  `host.db` or a declared tool.

## App example

```tsx
import { useMemo } from 'react';
import * as d3 from 'd3';

const DATA = [
  { month: 'Jan', value: 31 },
  { month: 'Feb', value: 44 },
  { month: 'Mar', value: 38 },
  { month: 'Apr', value: 57 },
  { month: 'May', value: 49 },
  { month: 'Jun', value: 66 },
];
const W = 640;
const H = 300;
const M = { top: 16, right: 16, bottom: 32, left: 40 };

export default function App() {
  const { x, y, line, ticks } = useMemo(() => {
    const x = d3
      .scaleBand()
      .domain(DATA.map((d) => d.month))
      .range([M.left, W - M.right])
      .padding(0.3);
    const y = d3
      .scaleLinear()
      .domain([0, d3.max(DATA, (d) => d.value)! * 1.1])
      .nice()
      .range([H - M.bottom, M.top]);
    const line = d3
      .line<(typeof DATA)[number]>()
      .x((d) => x(d.month)! + x.bandwidth() / 2)
      .y((d) => y(d.value))
      .curve(d3.curveMonotoneX);
    return { x, y, line, ticks: y.ticks(5) };
  }, []);
  return (
    <div className="p-4">
      <svg
        viewBox={`0 0 ${W} ${H}`}
        className="h-auto w-full max-w-3xl"
        role="img"
        aria-label="Monthly value"
      >
        {ticks.map((t) => (
          <g key={t}>
            <line
              x1={M.left}
              x2={W - M.right}
              y1={y(t)}
              y2={y(t)}
              style={{ stroke: 'var(--border)' }}
            />
            <text
              x={M.left - 8}
              y={y(t)}
              dy="0.32em"
              textAnchor="end"
              className="fill-muted-foreground text-xs"
            >
              {t}
            </text>
          </g>
        ))}
        {DATA.map((d) => (
          <g key={d.month}>
            <rect
              x={x(d.month)}
              y={y(d.value)}
              width={x.bandwidth()}
              height={y(0) - y(d.value)}
              rx={3}
              style={{ fill: 'var(--chart-1)' }}
            />
            <text
              x={x(d.month)! + x.bandwidth() / 2}
              y={H - 10}
              textAnchor="middle"
              className="fill-foreground text-xs"
            >
              {d.month}
            </text>
          </g>
        ))}
        <path
          d={line(DATA) ?? ''}
          fill="none"
          strokeWidth={2.5}
          style={{ stroke: 'var(--chart-2)' }}
        />
      </svg>
    </div>
  );
}
```
