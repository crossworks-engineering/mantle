# D3 in a canvas

Version: d3 7.9.0, as this brain's canvas runtime pins it.
Source: the D3 documentation (d3js.org) and its 6.0 and 7.0 release notes.
Written for Mantle, not copied.

## Import

```js
import * as d3 from 'd3';
```

The whole bundle, by its bare name. Use D3 when you place the marks
yourself: custom charts, schematics, force graphs, maps from inline
GeoJSON, scales and axes for hand-drawn SVG. For an ordinary bar or line
chart, ECharts is less work.

## Core API

- Selections: `d3.select('#c')`, `selection.selectAll('rect').data(rows).join('rect')`
  then `.attr(name, value)`, `.style(name, value)`, `.text(...)`. `join`
  does enter, update and exit in one call.
- Scales: `d3.scaleLinear().domain([0, max]).range([h, 0])`,
  `d3.scaleBand().domain(names).range([0, w]).padding(0.2)`,
  `d3.scaleTime()`, `d3.scaleOrdinal()`. Ticks: `scale.ticks(5)`.
- Axes: `g.call(d3.axisBottom(x))`, `d3.axisLeft(y)`.
- Shapes: `d3.line().x(...).y(...)`, `d3.area()`, `d3.arc()`, `d3.pie()`.
- Data: `d3.max`, `d3.extent`, `d3.group`, `d3.rollup`, `d3.bin`.
- Layouts: `d3.forceSimulation`, `d3.hierarchy` with `d3.tree` or
  `d3.treemap`, `d3.geoPath` with a projection.
- Transitions: `selection.transition().duration(600).attr(...)`.

## What changed (if you know D3 5 or earlier)

- ES modules only; `import * as d3 from 'd3'`, never `require` or a script
  tag from a CDN.
- No global `d3.event`: an event listener gets `(event, datum)`, and
  `d3.pointer(event)` replaced `d3.mouse`.
- `d3.nest` is gone: use `d3.group` and `d3.rollup`. `d3.histogram` is
  `d3.bin`.
- Prefer `selection.join` to the old `enter().append()` and `merge` chains.

## In a canvas

- Colours: in a style, a CSS variable works as it is:
  `.style('fill', 'var(--chart-1)')`, `'var(--foreground)'`,
  `'var(--border)'`, so the drawing follows the theme with no code.
- Size: a fixed `canvas:size` and an SVG with the same `width` and `height`
  (or a `viewBox`); the frame scales it to fit.
- Transitions and force layouts: skip the animation when
  `prefers-reduced-motion` asks (set the final attributes, or run the
  simulation to its end with `simulation.tick(300)` before drawing).
- No `d3.json` or `d3.csv` from a URL: the frame has no network. Put the
  data in the page.
- Check it with `present_render`; an empty chart usually means the scale's
  domain did not match the data.

## Example

```html
<!doctype html>
<html>
  <head>
    <title>Throughput by unit</title>
    <meta name="description" content="Weekly throughput of four units as bars with a value axis." />
    <meta name="canvas:size" content="1280x720" />
  </head>
  <body class="bg-background p-10 text-foreground">
    <h1 class="mb-6 text-4xl font-semibold">Throughput by unit</h1>
    <svg id="c" width="1200" height="560"></svg>
    <script type="module">
      import * as d3 from 'd3';
      const rows = [
        { unit: 'Unit 1', value: 420 },
        { unit: 'Unit 2', value: 515 },
        { unit: 'Unit 3', value: 380 },
        { unit: 'Unit 4', value: 465 },
      ];
      const m = { top: 10, right: 10, bottom: 40, left: 60 };
      const w = 1200 - m.left - m.right;
      const h = 560 - m.top - m.bottom;
      const g = d3.select('#c').append('g').attr('transform', `translate(${m.left},${m.top})`);
      const x = d3.scaleBand().domain(rows.map((d) => d.unit)).range([0, w]).padding(0.3);
      const y = d3.scaleLinear().domain([0, d3.max(rows, (d) => d.value) * 1.1]).range([h, 0]);
      g.append('g').attr('transform', `translate(0,${h})`).call(d3.axisBottom(x)).style('font-size', '16px');
      g.append('g').call(d3.axisLeft(y).ticks(5)).style('font-size', '16px');
      const reduce = matchMedia('(prefers-reduced-motion: reduce)').matches;
      const bars = g.selectAll('rect').data(rows).join('rect')
        .attr('x', (d) => x(d.unit)).attr('width', x.bandwidth())
        .style('fill', 'var(--chart-1)')
        .attr('y', h).attr('height', 0);
      (reduce ? bars : bars.transition().duration(600))
        .attr('y', (d) => y(d.value)).attr('height', (d) => h - y(d.value));
    </script>
  </body>
</html>
```
