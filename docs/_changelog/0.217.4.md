# 0.217.4 (2026-07-31)

Housekeeping after a busy day of fixes, and one build that had been broken
longer than anyone noticed.

## Fixes

- **The Windows desktop build has been failing since v0.216.7.** A build script
  set an environment variable using shell syntax that Windows does not
  understand, so the desktop app never got packaged for Windows on the last four
  releases. The Mac and Linux builds passed throughout, which is why it went
  unseen; the release itself was always fine. The script no longer depends on
  shell behaviour at all.

- **An imported Project plan with no summary rows lost its usage notes.** The
  guidance a plan carries, that durations are hours unless the column says
  days, that slack is in days, that rows are in plan order, was attached only
  to plans that had roll-up rows. A flat plan got a correct grid and no
  explanation of it.

## Notes

Nothing in this release changes behaviour for an existing brain; both fixes are
about something being absent that should have been there.
