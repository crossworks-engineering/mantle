# 0.232.33 (2026-08-22)

Finding a file stopped requiring you to remember where you put it.

## Recent files, across every folder

The files API can now answer "what changed lately" for the whole tree at
once, newest first, each row naming the folder it lives in. This backs the
file manager's new Recent view — the immediate answer to "where did that
upload land", which walking folders one by one never gave. An edit
resurfaces a file the same way a fresh upload does.

Search needed no server work at all: the existing search API already scopes
to the files subtree, so the client's new in-pane search rides it as-is —
ranked by meaning across names, summaries and content, with name-only files
matching on their name, type and tags exactly as the indexing switch
promises.
