# 0.206.12 (2026-07-27)

**The ink split, finished, and an audit that finds the next one.** v0.206.11
moved text off the fill colour across 141 `.tsx` files and never touched CSS.
This closes that gap and adds the check that would have caught it.

## Fixed

Twenty `color: var(--primary)` / `var(--destructive)` declarations across both
`globals.css` were still painting text with the **fill** colour: every link and
mention inside a Page, the `.prose-accent` headings/links/inline-code/markers,
the diff pills, and `hljs-deletion`. A Pages link rendered at **3.70:1** on the
`claude` light theme where the ink token gives **5.22:1**.

Tints and borders are untouched, only text moved.

## Added

### Ink audit: discovered, not enumerated

`themes.test.ts` asserts a hand-written list of pairs, which is exactly why
three instances of the same bug survived: a contract only covers the tokens it
enumerates. `ink-audit.test.ts` scans instead; it walks every stylesheet that
ships to a browser, extracts each `color:` declaration, resolves the token it
paints with, and measures that token against the surfaces it can land on across
all 42 themes and both modes. A new `color: var(--whatever)` is audited the
moment it is written.

It found the twenty declarations above on its first run.

Tokens that fail today are carried in a shrink-only `KNOWN_UNSAFE` baseline with
a reason each, the five `chart-*` tokens used by syntax highlighting and
callouts, `foreground` (one self-contradicting palette), and `muted-foreground`
on non-muted surfaces. The baseline cannot rot: a listed token that starts
passing fails the build asking for its entry to be deleted, and an entry for a
token nobody paints with fails as orphaned.

## Deploy

**Tag-only. No migrations, no compose change, no new env.**

⚠ **Roll the client stack**: the visible change is the owner UI's stylesheet,
and `docker compose up -d` does not roll `mantle_client_web`.

```
docker compose -f docker-compose.client.yml --project-directory . pull
docker compose -f docker-compose.client.yml --project-directory . up -d --wait
docker ps    # confirm mantle_client_web carries the new tag
```
