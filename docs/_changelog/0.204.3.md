# 0.204.3 — 2026-07-26

## Changed

- **Settings → Appearance tidied into a Brand section.** The logo upload and
  the wordmark/peer-name font pickers live together under **Brand** — the
  fonts used to appear twice (a sidebar Typography section *and* inside the
  Typography preview tab). The preview tab now shows only the type specimens
  and the blog-post sample.

## Fixed

- The Font Showcase card no longer nests its own scroll area inside the
  already-scrolling preview column — the double scrollbar is gone; the card
  sizes to its content and the column scrolls.
