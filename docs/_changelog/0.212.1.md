# 0.212.1 — 2026-07-29

## Fixed

- **Search boxes no longer rewind while you type** (`/models`, `/formulas`).
  Both screens debounce the search box into the URL, then synced the box back
  from the URL unconditionally — so the router echo of an in-flight commit
  ("cha") landed after further keystrokes and rewound "chatg" unless you typed
  slower than the round trip. The URL→input sync now skips while the field is
  focused; external changes (provider switch clearing the query, back/forward)
  still sync as before.
