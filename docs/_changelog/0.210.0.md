# 0.210.0 — 2026-07-29

**Diagrams and charts land in Pages — Mermaid as the single engine.** A
```` ```mermaid ```` fence (or the `/diagram` slash block) renders flowcharts,
mind maps, sequence diagrams, pies, bar/line charts, timelines and more from
plain text, themed to the active palette. The dialect principle behind it:
every Pages element must be human-writable and human-legible as markdown — a
prose-like DSL qualifies; an options-JSON blob in a fence never will (the
ECharts alternative was cut on exactly that rule).

## Added

### The `diagram` node

- **Authoring**: a ```` ```mermaid ```` fence in the dialect (agents are taught
  it in `rich_writing`; the `page_editing` prefix table + block tools know it),
  or the `/diagram` slash item in the editor. Nested fences inside callouts /
  columns / lists work; round-trips are byte-stable, including backtick-run
  fence widening.
- **Editor**: dual-mode NodeView — rendered SVG, click to edit source with a
  debounced live preview. Invalid source shows the parse error and keeps the
  last good render; source is never destroyed. Mermaid (11.16.0, exact-pinned,
  self-hosted) lazy-loads so it stays out of the main chunk. Theming maps
  `chart-1..5` to fills and foreground roles to text, re-rendering on theme
  and light/dark flips. `securityLevel: 'strict'`, no HTML labels.
- **Brain**: diagram source is indexed (`docToText`), so search recalls a
  diagram by its labels; `page_blocks_list` reports `kind: diagram` with the
  declared type (flowchart, mindmap, …) as meta.
- **Server surfaces** (`/s` share, print/PDF, team reader, docx, email)
  degrade to a labelled, escaped source block — never a blank, no markup
  pass-through.

### Markdown view

The page detail header gains a **Markdown** action: the page as the exact
dialect markdown agents read and write (draft edits included), with
copy-to-clipboard. The same serializer backs the existing `.md` export.
(`doc-to-markdown` is now a browser-safe leaf export of `@mantle/content`.)

## Fixed

Pre-release audit (three independent review passes) caught and fixed, before
any of it shipped:

- Diagram source edits silently not persisting unless Done/Escape was pressed
  (a per-render effect-cleanup cancelled every pending commit).
- ⌘S while typing in the diagram source panel opening the browser save dialog
  instead of committing the page (blanket `stopPropagation`; ⌘K was dead too).
- A single failed mermaid chunk load breaking all diagrams until full reload
  (rejected dynamic-import promise cached forever).
- Empty diagrams stealing focus on page load via an auto-opened, autofocused
  source panel.
- ` ```mermaid title=x ` info-string fences silently staying code blocks.
