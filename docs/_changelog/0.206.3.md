# 0.206.3 — 2026-07-27

**The API Console meets you where APIs live.** Vendor documentation universally
speaks cURL; the console now reads and writes it, and shapes a tool's arguments
from its schema instead of leaving you to hand-write JSON.

## Added

### cURL in, cURL out

Paste a cURL command from any vendor's docs and the request builder fills itself
in — method, headers, the `-d`/`--data` family, `--json`, `-u` basic auth, `-G`,
`--url`, quoted strings and backslash continuations. Anything the parser skips is
surfaced in `warnings` rather than dropped, so a lossy import says so out loud.

`toCurl` is the inverse, and it carries one hard rule: a `{{secret:service/label}}`
reference is emitted **verbatim, never resolved** — the plaintext lives server-side
and must not reach the clipboard. Environment `{{vars}}` (base URLs, ids) do
resolve, since that's what makes the copied command runnable. Both halves of that
rule are covered by tests (14 in `curl.test.ts`).

### Schema-formed arguments

Tool arguments render as a real form built from the tool's own schema, rather than
a raw JSON textarea.
