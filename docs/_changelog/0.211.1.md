# 0.211.1 — 2026-07-29

## Changed

- **The contacts gate is now stated where you connect a mailbox.** The
  add/edit IMAP account form opens with a detailed notice: connecting an
  account never imports the whole mailbox — syncs scan headers only, and a
  message is fetched and stored just when its sender is on the contacts list
  (exact address or `@domain` wildcard; your own addresses always pass;
  everything else is skipped without being downloaded, and adding a contact
  later backfills ~90 days of their mail). Shared component
  (`ContactsGateNotice`) so other mail-connect surfaces can mount the same
  explainer; the Outlook mail toggle already carried a one-line version.
