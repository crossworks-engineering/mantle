# 0.213.2 (2026-07-29)

Both found live during the astron re-provision, the first real run of the
full uninstall → fresh-install cycle.

## Fixed

- **`uninstall.sh` died right after its summary on any real deploy.** The
  data-dir size probe (`du | awk`) hit root-owned postgres/minio subdirs: du
  prints a partial total but exits non-zero, `pipefail` fails the command
  substitution, and `set -e` killed the script before it removed anything,
  while looking like a clean exit. Guarded; the partial size still shows.
- **The release deploy bundle now includes `scripts/uninstall.sh`**: the
  bundle's copy list in `release.yml` predated the uninstaller, so
  `mantle-deploy-*.tar.gz` shipped without it.
