# 0.213.1 (2026-07-29)

## Fixed

- **Uninstall now tears down the sandbox stack too**: a gap sharpened by
  sandboxes defaulting ON for fresh installs (v0.213.0). Ad-hoc sandbox
  containers (sandboxd's children, label-selected, invisible to every
  compose `down`) were left *running* after an uninstall, which also pinned
  the fixed-name `mantle_sandbox` / `mantle_sandbox_restricted` networks in
  place. The uninstaller now removes labelled sandbox containers first,
  passes `--profile sandboxes` explicitly (so sandboxd goes even if `.env` is
  already gone), and names both sandbox networks in the removal backstop.
  Sandbox `/files` work dirs are deliberately untouched, data decisions stay
  with the data section.
