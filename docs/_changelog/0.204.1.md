# 0.204.1 (2026-07-26)

Follow-up polish on the inline team reader release, cut mid-dev-test.

## Changed

- **The `/team` header carries the brain's brand the way the owner shell
  does.** The wordmark renders in the user-selectable wordmark font (it was
  pinned to the base logo face), the brain's **peer name** is centred in the
  page-title font and chart-2 (exactly the owner header's treatment) and the
  header picks up the primary-tinted gradient. Below `md` the centre shows the
  section label instead (the sidebar that names the section is hidden there).
  `GET /api/team/workspace` now includes `peerName`. One brand,
  admin-determined, both surfaces.

## Fixed

- `build-check` CI had failed on every main push since the Hono arc:
  `pnpm -r typecheck` ran against the gitignored `route-manifest.gen.ts`
  before anything generated it. A `pretypecheck` hook runs the generator
  (same mechanism as `predev`), which also un-breaks `pnpm verify` on a fresh
  clone. (The companion e2e-bootstrap fix, the explicit `MANTLE_MASTER_KEY`
  in `run-local.sh`, shipped in v0.204.0.)

## Upgrading

Nothing to do, no migrations, no config changes.
