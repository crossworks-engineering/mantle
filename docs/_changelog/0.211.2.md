# 0.211.2 — 2026-07-29

Audit pass over the new Models tab (v0.211.0) — every finding fixed.

## Fixed

- **The manifest-revert trap is now visible.** The boot reconcile force-syncs
  every manifest specialist's model/prompt/params back to the system default on
  upgrade (`syncSpecialistDefs`) — so an operator model change on Remy,
  Researcher, Pages, Docs & co. quietly reverts at the next update, and (worse)
  only `model` reverts, never `provider`/key, which can strand an incoherent
  cross-provider triple. The agent DTO now carries `manifestManaged`; those
  agents get a **system** badge in the Models matrix, a warning in the model
  picker, and the same warning in the Agents editor's model field (the trap
  predates the Models tab). The reconcile behaviour itself is unchanged —
  deliberate, pending a product decision on operator overrides.
- **Switching into `local`/`custom` warns about the route host.** Those routes
  need a Base URL the compact picker can't set (`custom` refuses to run
  without one; `local` falls back to the localhost default) — the picker now
  says so and deep-links to the full agent editor.
- **Stable matrix order.** Rows sort by role tier then name instead of the
  API's `updatedAt desc`, so Apply all no longer reshuffles the table under
  the ✓ marks.
- **Tab switcher locks mid-apply** — leaving would hide per-row progress and
  silently drop still-staged failures.
- **Failover visibility**: agents with a backup route show a muted
  `failover: provider/model` line, since a primary switch never touches the
  backup.
- **Empty-model submits surface a message** instead of silently doing nothing
  (ModelSelect's `required` isn't a native constraint); staged-prev
  comparisons now always resolve against the freshest agent list; sticky
  matrix header; empty-state panel for a zero-agent brain.
