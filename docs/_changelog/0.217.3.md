# 0.217.3 — 2026-07-31

Two fixes, both of the same shape: something failed quietly and reported success.

## Fixes

- **Files dropped into a watched folder were indexed by filename alone if the
  name had a capital letter in it.** The disk watcher recorded a lowercased
  version of the name while leaving the file on disk under its real one, so the
  path it later reconstructed did not exist and the parser was never reached —
  yet the ingest reported success. A 1094-task Microsoft Project plan went in as
  23 characters that way. Affects every format, not just plans. Deleting such a
  file from disk also left its entry behind; both halves now agree on the name,
  and existing entries correct themselves the next time the file is touched.

- **Semantic search silently fell back to keyword search on any brain that
  cannot be written to.** Each newly-computed embedding is cached, and a refused
  cache write took the whole embedding down with it. The search then degraded to
  full-text, so keyword lookups returned plausible results while questions asked
  in natural language returned nothing — with no error anywhere. The cache is an
  optimisation and no longer fails the search it exists to speed up; a brain that
  cannot cache simply recomputes, and says so once in the log.

## Notes

Both only bite where the database will not accept a write — a read-only replica,
a degraded database, a revoked grant, a role narrowed for least privilege — or,
for the first one, on any case-sensitive filesystem, which is to say every Linux
box. Neither produced an error message before this release, which is what made
them worth chasing.
