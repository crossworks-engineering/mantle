# 0.213.6 (2026-07-29)

Docs-only.

## Added

- `docs/scripts.md` §2 "Docker and compose": the four compose projects and
  their container names, dev/deployed/client/e2e command sets, profiles
  (`local-embedder`, `sandboxes`), one-shot services, ports, autoheal and log
  capping, and what is safe to prune. Documents two traps: `-p` does not
  isolate a second stack (every service pins `container_name`), and the
  client stack needs its own `-f docker-compose.client.yml
--project-directory .` or the owner UI silently stays on the old image.
