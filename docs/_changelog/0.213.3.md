# 0.213.3 (2026-07-29)

## Changed

- **Pages: Markdown mode is now a flat, full-pane source view.** Toggling
  *Markdown* on a page used to swap the rich editor for a boxed textarea
  floating in the centred document column, a form field with dead space all
  around it. The raw source now fills the whole editor pane: the header band
  (icon + title + tags) stays pinned on top and the textarea takes every
  remaining pixel, edge-to-edge with its own scroll, like a code file open
  under the page title. The width preference deliberately doesn't apply while
  in source view, and backlinks stay hidden until you toggle back. Layout
  only, the draft machinery underneath (debounced parse, autosave, ⌘S
  commit, blur flush, seeded remount on toggle) is untouched.
